# Suly — رفيقك نحو الالتزام

تطبيق Android عربي لمتابعة الصلاة والورد القرآني والأذكار والتسبيح، بتصميم هادئ أخضر وذهبي، وتنقل RTL من خمس خانات بترتيب الصفين الذي حدده المستخدم.

## الوظائف والبيانات

تُحسب مواقيت الصلاة على الجهاز باستخدام مكتبة `adhan`، مع اختيار طريقة الحساب ومذهب العصر، واستخدام المنطقة الزمنية المحددة للموقع في عرض الأوقات. يمكن اختيار المدينة يدويًا أو السماح بالموقع أثناء الاستخدام. إشعارات الصلاة محلية، لكل صلاة إعداداتها، ومنها خيار الصمت والتذكير الاختياري. قد يقيّد Android وصول الإشعار أو توقيته وفق الأذونات وتوفير البطارية. تُعاد جدولة الإشعارات يوميًا وعند العودة للتطبيق؛ وفي فجوة DST لا يُرسل التنبيه في ساعة أخرى مضللة، بل يُترك لذلك اليوم.

على Android، تحفظ سجلات الصلاة والنوافل وخطة القرآن والتقدم والمفضلة والعداد والإعدادات في SQLite محلية. أما معاينة الويب فقط فتستخدم AsyncStorage بديلًا كي تعمل دون مكوّن SQLite الأصلي الخاص بـ Android. لا تُرسل السجلات أو الأهداف الشخصية إلى الخادم.

مكتبة المحتوى تبدأ محليًا وتظل قابلة للاستخدام دون اتصال. يتطلب فحص الإصدارات المنشورة وتنزيلها اتصالًا؛ يعرض التطبيق إصدارًا أحدث إن توفر، ولا يثبته إلا بعد ضغط المستخدم على «تحديث الآن». يرفض التطبيق الإصدار المتساوي أو الأقدم، ولا يستبدل المكتبة عند فشل الاتصال أو عدم وجود نشر. المزامنة للمحتوى المنشور وحده، ولا تحدّث ملفات التطبيق أو واجهته؛ تغييرات الوظائف تحتاج بناءً جديدًا.

أضيف قارئ مصحف كامل يعمل دون اتصال، مبني على نص Tanzil العثماني وبيانات 604 صفحات. يحفظ التطبيق آخر صفحة وعلامة مرجعية والصفحات التي علّمها المستخدم كمقروءة محليًا؛ وعند اختيار هدف الورد بوحدة الصفحات يُحسب تقدم اليوم من الصفحات المسجلة. المصدر وشروط استخدام النص موثقان في [QURAN_SOURCE.md](QURAN_SOURCE.md).

## لوحة الإدارة — واجهة متصفح منفصلة

مسار الويب `/admin` هو لوحة الإدارة المستقلة؛ أُزيل رابطها من إعدادات APK، ويعرض مسار Android رسالة تفيد بأن الإدارة تتم من المتصفح. النطاق الثابت للمشروع هو `https://suly-ky79x.manus.space`، وقد ضُبط عنوان API وOAuth وCORS عليه. في آخر فحص عام أعاد `/` و`/admin` الحالة 404 رغم ظهور Express مستمعًا في سجلات الحاوية؛ لذا النطاق ولوحة الإدارة غير مؤكدَي العمل حتى يُصلح توجيه النشر. لا يُقدَّم رابط Preview المؤقت باعتباره رابط الإنتاج.

تستخدم لوحة الويب Manus OAuth، وتتحقق إجراءات الإدارة من الدور على الخادم. تُحفظ المسودات والمصادر والمراجعة وإصدارات المحتوى في قاعدة بيانات المشروع؛ يجب مراجعة المصدر قبل نشر أي آية أو حديث. لا تتحول المسودة إلى محتوى منشور حتى ينشر المشرف إصدارًا. إعداد `OWNER_OPEN_ID` مضبوط في إعدادات المشروع لكل البيئات؛ ويثق الخادم بطبقة ingress واحدة عند تفسير HTTPS لتعيين كوكيز `Secure; SameSite=None`. لم نتحقق بعد من أن الحساب الذي سيسجل الدخول يطابق المالك المصرح به. لا تضع المعرّف داخل APK أو في مستودع الشيفرة.

بعد نشر إصدار المحتوى، يفتحه المستخدم من **الأذكار** ويضغط **تحديث الآن** عند ظهور إصدار أحدث. تغيير واجهة التطبيق أو الوظائف يحتاج إعادة بناء APK؛ لا يوجد تحديث شيفرة تلقائي OTA مهيأ في المشروع. رُفع رقم النسخة القادمة إلى `1.0.3` ورقم بناء Android إلى `4` حتى يثبت APK التالي كتحديث فوق `1.0.2` / Build 3.

تتضمن النسخة القادمة المصحف كاملًا محليًا، لذا تعمل القراءة وتتبع الصفحات دون API أو اتصال. ويستخدم التطبيق العنوان الثابت `https://suly-ky79x.manus.space` فقط للوظائف الاختيارية المتصلة مثل تحديث المحتوى وتدفق لوحة الإدارة؛ هذه الوظائف لا تُعد متاحة إلى أن ينجح النطاق العام.

## التطوير والفحوص

```bash
pnpm install --frozen-lockfile
pnpm db:push
pnpm dev
```

يخدم `pnpm dev` Metro للمعاينة على المنفذ 8081 وخادم API على المنفذ 3000. شُغّل `pnpm db:push` قبل أول حركة OAuth/API في نسخة بيئة جديدة، وأعده فقط عند تغيير المخطط أو الحاجة إلى مزامنة جديدة. قاعدة بيانات المشروع المدارة مشتركة بين التطوير والنشر، لذا لا تستخدمها لاختبارات إتلافية.

```bash
pnpm test
pnpm check
pnpm build
pnpm exec expo export --platform web --output-dir /tmp/suly-web-export
```

آخر تحقق مكتمل: 61 اختبارًا ناجحًا واختبار واحد متجاوز، مع نجاح `pnpm check` و`pnpm lint` و`pnpm build` وتصدير Expo Web الذي يتضمن `/quran-reader`. فحوص بيانات المصحف تقارن نص كل آية حرفيًا بالمصدر وتثبت 6236 آية و114 سورة و604 صفحات. في اختبار خادم الإنتاج المحلي أعاد `/admin` و`/api/health` الحالة 200، وأعاد `/api` الحالة 404 بدل صفحة التطبيق، وقُبل أصل CORS الإنتاجي المطابق. لم يُختبر تسجيل دخول المالك الفعلي أو تثبيت APK جديد على Android بعد. حذّر تصدير الويب فقط من أن إشعار تغيّر push token غير مدعوم بالكامل على Web؛ إشعارات المتصفح ليست مسار المنتج الأصلي.

## بناء Android

مشروع Expo معدّ للبناء على Android ويحافظ على `applicationId` وscheme المولّدين. إصدار APK أو AAB يتم من لوحة المشروع عبر إجراء بناء Android؛ لا تُنفّذ EAS أو بناء إصدار Android داخل Sandbox. الإصدار القادم هو `1.0.3` / `versionCode 4`؛ يُبنى من لوحة المشروع بعد حفظ checkpoint. لم يتوفر تثبيت أو فحص فعلي على جهاز Android لهذه النسخة، لذا لا تدّعي معاينة الويب أو اختبارات TypeScript وحدها أن التنبيهات والتخزين الأصليين قد اختُبرا.
