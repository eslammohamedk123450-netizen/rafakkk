# رفيقك نحو الالتزام

تطبيق Android عربي يعمل محليًا لمساعدة المستخدم على الصلاة والقرآن والأذكار والذكر، بتجربة هادئة وودودة. **لا يحتاج التطبيق الأساسي إلى حساب أو خادم أو اتصال دائم بالإنترنت.**

## ما يعمل داخل التطبيق دون اتصال

- مواقيت الصلاة تُحسب على الجهاز باستخدام مكتبة `adhan`، مع اختيار طريقة الحساب ومذهب العصر، وتحديد الموقع يدويًا أو بإذن الموقع أثناء الاستخدام.
- المصحف العثماني كاملًا وبيانات صفحاته الـ604 محفوظة ضمن ملفات التطبيق.
- تسجيل الصلاة والورد القرآني والتقدم والعلامات المرجعية والمفضلة والأذكار والتسبيح والأهداف محفوظ محليًا في SQLite على Android.
- الأذكار والنصوص الأساسية والقصص محفوظة داخل التطبيق، مع عرض مصادرها ومراجعها.
- تسجيلات الأذان الثلاثة محفوظة محليًا داخل التطبيق، ويختار المستخدم التسجيل الذي يفضله.
- رسائل رفيقك التشجيعية، بما فيها آيات وأحاديث موثقة بمراجعها، تُجدول محليًا على الجهاز بعد موافقة المستخدم.
- لا توجد خدمة foreground دائمة أو عملية JavaScript تعمل باستمرار لمراقبة الوقت. التطبيق يجهّز الإشعارات، ويترك لنظام Android تنفيذ التنبيهات المجدولة. قد تتأثر دقة الوصول بأذونات النظام وتوفير الطاقة وسياسات الشركة المصنّعة.

## الخصوصية والاتصال

لا يرفع التطبيق سجلات الصلاة أو القراءة أو الذكر أو الموقع إلى خادم. بيانات المستخدم تبقى على جهازه. لا يتطلب تشغيل الوظائف الأساسية تسجيل دخول.

بعض الإضافات اختيارية وتحتاج إنترنت عند استخدامها، مثل بث إذاعة القرآن أو البحث عن تلاوات وتنزيلها، وفتح الروابط الخارجية للمصادر. هذه الإضافات لا تشغّل خدمة خلفية دائمة، ولا تمنع استخدام المصحف والأذكار وسجل العبادات دون اتصال.

معاينة الويب تستخدم تخزينًا محليًا بديلًا عبر AsyncStorage؛ تخزين Android الأصلي يستخدم SQLite.

## الإشعارات

- الأذان والتنبيهات ورسائل التشجيع تُجدول محليًا على الجهاز.
- رسائل رفيقك هادئة وصامتة افتراضيًا، ويمكن للمستخدم إيقافها أو اختيار تصنيفاتها وأوقاتها وفترة الهدوء.
- يعتمد التخصيص على النشاط الذي يسجله المستخدم داخل التطبيق فقط؛ لا يمكن للتطبيق معرفة الصلاة أو القراءة خارج التطبيق تلقائيًا.
- قد يقيّد Android الإشعارات أو يؤخرها إذا كانت الأذونات أو إعدادات البطارية تمنع ذلك. لا نعد بدقة مطلقة قبل اختبار نسخة Android على أجهزة فعلية.
- عند تغيير الموقع أو طريقة الحساب أو التفضيلات أو سجل العبادات، يعيد التطبيق تجهيز التنبيهات عند عمله في الواجهة.

## لوحة الإدارة والمعاينة

واجهة `/admin` على الويب أداة منفصلة للمراجعة والتطوير، وقد تحتاج خدمات API وتسجيل دخول. **ليست مطلوبة لتشغيل تطبيق Android**، ولا تُستخدم لإدارة بيانات المستخدم الشخصية. لا يحتوي تطبيق Android على اعتماد تشغيلي عليها.

## التطوير والفحوص

`pnpm install --frozen-lockfile` ثم `pnpm dev:metro` لتشغيل معاينة التطبيق. أدوات لوحة الويب الاختيارية فقط تستخدم أوامر الخادم في `package.json`. لا تحتاج وظائف التطبيق المحلية إلى تشغيل خادم API.

`pnpm check` و`pnpm test` و`pnpm exec expo export --platform web --output-dir /tmp/suly-web-export` هي أوامر الفحص والتصدير.

## المصحف والمصادر

مصدر النص العثماني وشروط استخدامه موثقان في [QURAN_SOURCE.md](QURAN_SOURCE.md). تُعرض مراجع الأذكار والآيات والأحاديث داخل التطبيق، ويجب المحافظة على توثيق كل مادة دينية قبل إضافة محتوى جديد.

## بناء Android

مشروع Expo معدّ للبناء على Android. يجب بناء APK/AAB وتثبيته واختبار الإشعارات والصوت والتخزين على جهاز Android فعلي قبل إعلان اكتمال اختبار النسخة. نجاح معاينة الويب أو TypeScript وحده لا يثبت عمل الأذان على كل أجهزة Android.
